# 财报分析第 2 轮：数据入口解耦

日期：2026-09-25。对应开发计划第 2 轮；不涉及第 3 轮的 PDF 指标提取修复。

## 实现范围

- `types.ts` 新增版本化 `ReportData`，包含报告、来源、事实、计算、发现、指标、趋势、执行步骤及章节展示数据。
- `FinancialAnalysisPage` 必须显式接收 `data`。`ReportDataProvider` 提供当前快照与索引；切换报告、run 或 revision 会重新创建工作区，清除上一份报告的面板选择与追问状态。
- `mock-report.ts` 是唯一引用 `mock-data.ts` 的适配器。原有示例内容被移到数据层，Web 路由与离线演示入口显式选择这个适配器。
- 章节内年份、比较期列、图表数据、比率、结论、Agent 文案、来源和文件列表由当前数据驱动。缺项显示未披露/不可计算/暂无数据；不会回退到示例数字。
- 指标、事实、计算与来源可独立打开证据，不要求先关联一条研究发现。关键报表中比较期来源分别可点击。无效引用不会导致页面崩溃或跳到第一条示例发现。
- 固定问答仅在 `mode: 'demo'` 时可用；报告模式明确显示追问尚未接入，完整问答服务属于第 7 轮。

未修改 `mock-data.ts`、CSS、财报 Skill 模板或原交付 `DB-GPT-Financial-Analysis-Demo.html`。保留原工作区分栏、报告章节结构、图表组件和 Manus Agent 面板。

## 验证

从仓库根目录：

```powershell
node standalone/financial-analysis/test-data.cjs
node standalone/financial-analysis/build.cjs .work/financial-analysis/demo-round2.html
```

回归使用真实 React/Ant Design 服务端渲染，并对图表和 Manus 面板捕获传入数据；它不替代浏览器布局验收。`report-fixtures.ts` 是明确标注的虚构测试数据，不使用两份 PDF 的数字，也不会由正常页面入口加载。

覆盖内容：

- 原 mock 经过新数据入口仍可渲染。
- 替换公司、年份为 2024/2022/2020，比较期列同步变化；单期趋势与负值保留。
- 空报告、缺少事实/计算/证据/文件、无研究发现都可渲染。
- 指标无 finding 时仍可查看来源；比较期来源单独跳转；错误 finding 不回退到示例。
- 未完成步骤不显示为完成；空输出列表不生成虚构文件。
- 非 demo 模式不会出现原公司的结论、比率或固定追问建议。

变更文件 ESLint 通过。数据契约及两个数据适配 fixture 单独通过严格 TypeScript 检查。全站检查与 Git HEAD 对比为 **138 → 138，新增 0**；既有错误位于其他模块，本轮没有扩展修复范围。离线构建成功，产物位于忽略目录；财报路由与后端健康检查均返回 HTTP 200。

当前自动化接口没有可连接浏览器，因此尚未确认所有点击操作的浏览器表现和视觉像素一致性。可以在 `http://127.0.0.1:3000/financial-analysis/` 检查原 demo 的章节、来源与执行面板。
