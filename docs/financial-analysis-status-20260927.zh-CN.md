## 当前结论

已接通“上传 PDF → 财务事实与计算 → 原文核对 → Qwen 分析 → 当前报告追问”主链路，适合保存为个人内测 Alpha。代码已推进至第 7 轮，但不等于完成原计划的七分之八：第 6 轮结论覆盖仍不足，第 7 轮还需用户验收，第 8 轮只有底层持久化和失败处理等部分能力提前实现。

不使用缺乏依据的百分比衡量完成度；是否可交付应按验收项判断。当前不宜标记为正式 v1 或将“数字与引用通过校验”理解为结论正确率。

## 仍需完成的具体项

1. **报告历史与重新打开。** 当前后端只有创建和按 ID 查询任务/报告等接口，没有任务列表接口。持久化不等于有可用的历史入口；需要按当前 owner 分页列出真实记录，并携带正确 session/run 信息重新打开。
2. **报告导出与真实产物。** 当前真实报告 `artifacts` 为空，Agent 产物标记 `downloadable: false`；文件面板主要打开来源或报告。原 PDF 下载已实现，分析报告 JSON/HTML 下载尚未实现。应从同一已保存 revision 导出并登记产物，沿用现有文件区域。
3. **执行状态与耗时。** 已有真实提取、计算、模型阶段及失败信息，但报告数据就绪后 run 会先标 completed，模型可能仍在执行。顶栏及 Agent 的总状态需要统一表达；还缺完善的阶段耗时展示。状态收敛放在现有区域，不能重新添加报告横幅。
4. **分析质量与样本扩展。** 第 6 轮结构化分析仍可能丢弃多数条目；问答也可能只展示引用数据。需要核对前三条关键结论、减少重复表达，并补第三家独立年报，覆盖不同表格版式。
5. **真实浏览器验收。** 完整走通上传、切换章节、追问、点击依据、原文跳页、失败重试、刷新和重新打开。自动测试尚未替代这些人工操作。

OCR、全篇附注检索、多年多文件对齐、行业对标、多用户生产部署属于后续能力，不计入本轮已经完成的内容。
